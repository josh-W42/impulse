# M6 — General Convex Shapes + Interaction: Design + Lean Plan

**Date:** 2026-09-26 · **Status:** approved · **Parent:** `2026-09-24-impulse-engine-design.md`
Two deployable halves: **M6a** (GJK/EPA, capsules, raycasts, mouse drag/throw) and
**M6b** (convex hulls: quickhull, mass properties, face-clipping manifolds).

## Design (approach A)

- **GJK + EPA over support functions** for convex pairs without a closed form: GJK
  (boolean, simplex containing the origin) then EPA (expanding polytope → penetration
  normal + depth). Shape-aware **manifold builders** turn the normal into multi-point
  patches: capsule segment endpoints (≤ 2 points), polytopes via M3 face clipping.
  SAT stays for box–box. Rejected: single-point GJK/EPA + persistent manifold
  (wobbles until filled; overlaps the M4 cache), per-pair closed forms only.
- **Capsule:** `Collider::Capsule { half_height, radius }` along local Y. Pairs:
  plane (endpoint spheres), sphere (closest point on segment), capsule (closest points
  between segments; 2 points when parallel and overlapping), box (endpoint spheres
  via sphere–box, else one EPA point).
- **Raycasts:** `World::raycast(origin, dir, max_t)` → nearest `RayHit { body, t,
  point, normal }`; broadphase tree traversal (slab test), exact per shape.
- **Mouse drag/throw:** click raycasts to a body + local anchor; a spring-damper pulls
  the anchor toward the cursor on a camera-parallel plane via `apply_impulse_at`
  (which wakes the body); release keeps velocity (throw). Left-drag on empty space
  still orbits.

## M6a tasks (TDD; clippy ×2; commit each)

**G1. GJK + EPA** — tests: overlap/separation agrees with sphere and SAT box results;
EPA depth/normal matches analytic sphere–sphere and SAT box–box on random overlapping
poses (independent cross-check).
**G2. Capsule collider** — validation, AABB, inertia (→ sphere as h→0, → rod as r→0).
**G3. Capsule contacts** — lying capsule rests on 2 points without rolling; capsule
on box, capsule–capsule, capsule–sphere cases; all prior tests pass.
**G4. Raycasts** — analytic hits per shape, nearest of several, misses, max distance.
**G5. Drag/throw** — `apply_impulse_at`, cursor-ray unprojection (tested), engine
wiring, panel hint.
**G6. Demo** — capsules join the Pit; drag works in every scene.
**G7. Verify + ship.**

## M6b tasks (after M6a ships)

Quickhull (convex, contains all inputs), hull mass properties (tetrahedral
decomposition; matches box formulas), hull contacts (EPA normal + face clipping),
hull raycast, demo + verify + ship.

## M6a results (2026-09-26)

- GJK (boolean, Muratori simplex cases) + EPA (horizon-edge polytope expansion).
  Independent cross-check: on 300 random box poses, GJK/EPA and the M3 SAT code agree
  on every overlap decision; depths match within 2 cm where normals agree.
- Capsules: inertia (sphere and rod limits tested), bounds, contacts with every shape.
  A test caught a patch bug: where one capsule overhangs another's cap, a slanted
  sliver won the "farthest point" pick; second points must now share the deepest
  point's normal (dot > 0.95).
- Raycasts: tree traversal (slab test) + exact sphere/box/plane/capsule; 6 analytic
  tests. `apply_impulse_at` wakes bodies.
- Drag/throw: cursor-ray unprojection (unit-tested), spring 80/s², damping 18/s,
  gravity cancelled, acceleration capped at 200 m/s²; mouse only (touch still orbits).
- Verified: WebGPU (dragged the tower's top box off in the browser) + WebGL2, native
  debug (user: capsules settle lying, grab/throw, orbit on empty space, waking).
