# M10 — Scene Hierarchy: Design + Lean Plan

**Date:** 2026-09-27 · **Status:** approved (design) · **Parent:** `2026-09-24-impulse-engine-design.md`
**Builds on:** `2026-09-26-m8-scene-editor.md` (scene format, editor, flat objects list)

## Purpose

Organise the scene as a tree, and move things together while editing. Any object
can parent others (Unity-style); an object with no shape and a static body — the
existing "anchor", shown as **empty** — serves as a folder. Parenting is an
edit-time relationship: at Play every body is independent. There is no physics
coupling or compound bodies.

## Design

**Format v2** (approach A: local poses, joints relative to body `a`):
- `ObjectDesc.parent: Option<usize>` (a flat list; parent is an index).
- `position` and `rotation_deg` are relative to the parent, or to the world at
  the top level.
- World pose = parent world ∘ local (translation and rotation; no scale
  inheritance).
- Validation errors: a missing parent, a self-parent, a cycle.
- Joint pivots, the hinge axis and the cone axis are stored in object `a`'s
  frame; distance anchors are stored in each body's own frame. They are
  converted to world at build.
- A subtree moved together keeps its joints; moving one side stretches them,
  and physics resolves that at Play.
- **Migration:** v1 files load and are converted automatically (world poses are
  local for parentless objects; world joints are converted into `a`'s frame
  using the authored pose). They build the same world as before. Saving writes
  v2.
- **Capture pose** skips jointed bodies (as in M8); captured bodies store local
  poses relative to their parent's captured world pose.
- **Demos** stay flat, except the ragdoll (parented under its torso) and the
  bridge planks (under a "bridge" empty), which exercise relative joints.

**Editor:**
- **Tree view:** collapsible rows.
- **Reparenting:** drag a row onto a row, or onto "(top level)" to unparent.
  Reparenting keeps the world pose. Drops onto yourself or a descendant are
  refused with a message.
- **Filter:** shows matches as a flat list with paths (`bridge › plank 4`).
- **Inspector:** a parent dropdown (excluding the object and its descendants);
  local pose fields, labelled relative to the parent.
- **Subtree operations:** move carries descendants; delete removes the subtree
  and any joints touching it; duplicate copies the subtree and its internal
  joints, remapped. Each is one undo step.
- **Add → Empty.**
- **Viewport:** picking selects the clicked object; descendants of the
  selection get a fainter outline.
- **Deferred:** multi-select, sibling reordering, prefabs, Play-time coupling.

## Results

- 231 tests pass. New tests cover:
  - **Format:** world poses compose through a three-level chain (translation
    and rotation); a missing parent, a self-parent and a cycle each give a
    specific error; joints stored relative to their bodies survive moving
    their shared parent, and the pivot follows `a` when only `a` moves.
  - **Migration:** a hand-written v1 file migrates, and every demo written as
    v1 builds the same world (bodies and joint anchors at the authored
    points).
  - **Editor:** subtree delete (renumbering parents and joints); subtree
    duplicate (inner joints copied and remapped); reparent keeps world poses
    and refuses loops; each is one undo step; capture stores parent-relative
    poses.
  - **UI:** tree rows nest children, collapse, and survive a cycle; filter
    paths; the outliner changes nothing when idle.
  - **Demos:** the grouped Joints demo (ragdoll skeleton, bridge under an
    empty) builds the same world as flat.
- **Verified in the browser:** the tree view; dragging a row onto "bridge"
  reparents it (indented, parent shown in the inspector, relative position,
  undoable).
- **Found along the way:** egui's default font has no ▸/▾ glyphs (they drew as
  boxes), so the toggles use +/−.
- **Not verified by automation:** precise drag targets, since the throttled
  pane delivers press and moves in one frame so the dragged row isn't always
  the one aimed at, and the loop-refusal message. Covered by the manual check.
