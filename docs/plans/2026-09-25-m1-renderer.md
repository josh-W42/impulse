## Phase A — pure logic (TDD, no GPU)

### A1. physics: `RigidBody`, `World`, handles, gravity — `crates/physics/src/{lib,body,world}.rs`
- `BodyKind { Dynamic { mass }, Static }`; `BodyDesc { kind, position, orientation, velocity }` with
  `BodyDesc::dynamic(mass, pos)` / `BodyDesc::fixed(pos)`.
- `BodyError { NonFinite, InvalidMass, InvalidOrientation }` (Display + Error).
- `RigidBody` private fields + getters (`position`, `orientation`, `velocity`, `kind`, `inverse_mass`).
- `World::new(gravity)`, `Default` = `(0, -9.81, 0)`; `add_body -> Result<BodyHandle, BodyError>`,
  `remove_body -> Option<RigidBody>`, `body(h) -> Option<&RigidBody>`, `bodies()` iterator,
  `len/is_empty`, `clear()` (bumps generations), `step(dt)` = semi-implicit Euler (v += g·dt; x += v·dt;
  static skipped; `debug_assert!` finite).
- Generational arena: `Slot { generation, body: Option<RigidBody> }` + free list.

Tests: free-fall velocity exact within 1e-3 after 2 s; position error ≤ g·t·dt and ratio of errors
for dt vs dt/2 in 0.45..0.55; static never moves; rejects NaN pos / inf vel / mass 0, -1, NaN / zero
quaternion; removed handle → None, remove twice → None, reused slot doesn't revive old handle;
`clear` invalidates handles; two identical worlds stepped 300× are bit-identical; `step(0)` no-op.
Run `scripts/check-physics-deps.sh` (must report `glam` only).

### A2. engine: `FixedTimestep` — `crates/engine/src/timestep.rs`
`FixedTimestep::new(step, max_steps)`, `advance(frame_time) -> StepPlan { steps, alpha }`, `reset()`.
Non-finite/negative frame time → 0. When capped, drop excess with `accumulator %= step`.
Tests (use step = 1/64 to avoid float ties): 3/64 → 3 steps α=0; 1/128 → 0 steps α=0.5, again → 1
step α=0; cap 5 on 1.0 s with α∈[0,1); NaN/negative → 0 steps; α∈[0,1) over 1000 LCG-random frames.

### A3. engine: `Pose` + interpolation — `crates/engine/src/pose.rs`
`Pose { position, orientation }`, `interpolate(prev, curr, alpha)` (lerp + slerp).
Tests: α=0 → prev, α=1 → curr, α=0.5 → midpoint and 45° between 0° and 90° about Y.

### A4. engine: cameras — `crates/engine/src/camera.rs`
- `OrbitCamera { target, yaw, pitch, distance }`: `eye()` = target + d·(cp·sy, sp, cp·cy);
  `rotate(dyaw, dpitch)` (pitch clamped ±1.5), `zoom(factor)` (distance clamped 1..200), `pan(right, up)`
  (scaled by distance), `view()` = `look_at_rh`.
- `FlyCamera { position, yaw, pitch }`: `forward()` = (−sy·cp, sp, −cy·cp); `right()`; `look(dx, dy)`
  (yaw −= dx, pitch −= dy, clamped); `translate(fwd, right, up)`; `view()` = `look_to_rh`.
- `CameraRig { mode: Orbit|Fly, orbit, fly }`: `toggle()` syncs fly from orbit (position = eye,
  yaw = yaw, pitch = −pitch) and back (target = pos + fwd·distance); `view()`, `eye()`,
  `projection(aspect)` = `perspective_rh(60°, aspect.max(1e-3), 0.1, 500)`.
Tests: pitch clamp holds under huge input; zoom clamps; orbit forward == −(eye−target) dir; toggle
Orbit→Fly keeps eye and view direction (≈1e-4); Fly→Orbit→Fly round-trip keeps position; fly
`translate(1,0,0)` moves along `forward()`.

### A5. engine: `InputState` — `crates/engine/src/input.rs`
Decoded API (winit types with private fields aren't constructible in tests):
`on_key(KeyCode, pressed)`, `on_mouse_button(MouseButton, pressed)`, `on_cursor_moved(Vec2)`,
`on_wheel(lines)`, `on_raw_motion(Vec2)`, `on_touch(id, phase, Vec2)`; queries `key_held`,
`key_pressed` (this frame), `button_held`, `cursor_delta`, `raw_delta`, `wheel`, `touch_rotate()`
(one finger delta), `touch_pinch()` (distance ratio); `end_frame()` clears per-frame values.
Tests: press/release/held; pressed only for one frame; deltas accumulate and clear; first cursor
move produces no delta; pinch ratio 2.0 when fingers spread from 100 px to 200 px; lifting a finger
ends pinch.

### A6. engine: `EguiInput` — `crates/engine/src/egui_input.rs`
Per design findings: cursor (physical px → points), buttons (only with a known pointer pos), wheel
(`LineDelta` → Line; `PixelDelta` → Point / ppp), cursor left → `PointerGone`, focus, first touch →
pointer move/press/release. `take(size_in_pixels, time) -> RawInput` sets `screen_rect` (points),
`time`, `focused`, `viewports[ROOT].native_pixels_per_point`, and drains events.
Tests: (200,100) at ppp 2 → `PointerMoved(100,50)`; button before any move → no event; screen_rect
= size/ppp; `take` drains events; pixel wheel divided by ppp.

## Exact code: shaders (B4)

`scene.wgsl`:
```wgsl
struct Globals {
    view_proj: mat4x4<f32>,
    light_view_proj: mat4x4<f32>,
    eye: vec4<f32>,
    light_dir: vec4<f32>,   // direction light travels, normalized
    light_color: vec4<f32>,
};
@group(0) @binding(0) var<uniform> globals: Globals;
@group(0) @binding(1) var shadow_map: texture_depth_2d;
@group(0) @binding(2) var shadow_sampler: sampler_comparison;

struct VertexIn { @location(0) position: vec3<f32>, @location(1) normal: vec3<f32> };
struct InstanceIn {
    @location(2) model_0: vec4<f32>, @location(3) model_1: vec4<f32>,
    @location(4) model_2: vec4<f32>, @location(5) model_3: vec4<f32>,
    @location(6) normal_0: vec4<f32>, @location(7) normal_1: vec4<f32>,
    @location(8) normal_2: vec4<f32>, @location(9) color: vec4<f32>,
};
struct VertexOut {
    @builtin(position) clip: vec4<f32>,
    @location(0) world_pos: vec3<f32>,
    @location(1) normal: vec3<f32>,
    @location(2) color: vec4<f32>,
    @location(3) light_clip: vec4<f32>,
};

fn model_matrix(i: InstanceIn) -> mat4x4<f32> {
    return mat4x4<f32>(i.model_0, i.model_1, i.model_2, i.model_3);
}

@vertex
fn vs_main(v: VertexIn, i: InstanceIn) -> VertexOut {
    let world = model_matrix(i) * vec4<f32>(v.position, 1.0);
    let normal_matrix = mat3x3<f32>(i.normal_0.xyz, i.normal_1.xyz, i.normal_2.xyz);
    var out: VertexOut;
    out.clip = globals.view_proj * world;
    out.world_pos = world.xyz;
    out.normal = normal_matrix * v.normal;
    out.color = i.color;
    out.light_clip = globals.light_view_proj * world;
    return out;
}

@vertex
fn vs_shadow(v: VertexIn, i: InstanceIn) -> @builtin(position) vec4<f32> {
    return globals.light_view_proj * model_matrix(i) * vec4<f32>(v.position, 1.0);
}

fn shadow_factor(light_clip: vec4<f32>) -> f32 {
    let ndc = light_clip.xyz / light_clip.w;
    let uv = ndc.xy * vec2<f32>(0.5, -0.5) + vec2<f32>(0.5, 0.5);
    if (any(uv < vec2<f32>(0.0)) || any(uv > vec2<f32>(1.0)) || ndc.z > 1.0) {
        return 1.0;
    }
    // 3x3 PCF on top of the hardware 2x2 comparison filter. The Level variant is
    // allowed in non-uniform control flow (no implicit derivatives).
    let texel = 1.0 / vec2<f32>(textureDimensions(shadow_map));
    var sum = 0.0;
    for (var y = -1; y <= 1; y += 1) {
        for (var x = -1; x <= 1; x += 1) {
            let offset = vec2<f32>(f32(x), f32(y)) * texel;
            sum += textureSampleCompareLevel(shadow_map, shadow_sampler, uv + offset, ndc.z);
        }
    }
    return sum / 9.0;
}

@fragment
fn fs_main(in: VertexOut) -> @location(0) vec4<f32> {
    let n = normalize(in.normal);
    let l = -globals.light_dir.xyz;
    let v = normalize(globals.eye.xyz - in.world_pos);
    let h = normalize(l + v);
    let shadow = shadow_factor(in.light_clip);
    let n_dot_l = max(dot(n, l), 0.0);
    let specular = pow(max(dot(n, h), 0.0), 32.0) * 0.25 * step(0.0001, n_dot_l);
    let ambient = mix(vec3<f32>(0.22, 0.20, 0.18), vec3<f32>(0.50, 0.60, 0.75), n.y * 0.5 + 0.5) * 0.35;
    let light = globals.light_color.rgb * shadow;
    let rgb = in.color.rgb * (ambient + light * n_dot_l) + light * specular;
    return vec4<f32>(rgb, in.color.a);
}
```

```wgsl
struct Globals { view_proj: mat4x4<f32> };  // prefix of scene Globals; same buffer
@group(0) @binding(0) var<uniform> globals: Globals;

struct VertexOut { @builtin(position) clip: vec4<f32>, @location(0) color: vec4<f32> };

@vertex
fn vs_main(@location(0) position: vec3<f32>, @location(1) color: vec4<f32>) -> VertexOut {
    var out: VertexOut;
    out.clip = globals.view_proj * vec4<f32>(position, 1.0);
    out.color = color;
    return out;
}

@fragment
fn fs_main(in: VertexOut) -> @location(0) vec4<f32> { return in.color; }
```
